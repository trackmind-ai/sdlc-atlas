# /architecture
Greenfield only (enterprise phase; available on demand in any profile). Invoke
architecture-agent: candidate architectures compared, developer interviewed on
shape-changing questions only, decisions recorded as ADRs, output
docs/architecture/system-architecture.md in the repo. Next step: /bootstrap.

Interview-first contract (mandatory):
- Do NOT assume any major choice for a new project.
- Ask the developer every architecture decision before finalizing.
- For each decision, propose options with recommendation + trade-offs, then capture
  the developer's selected choice as an explicit decision.
- If required information is missing, keep interviewing; do not finalize by guessing.
- Finalize only after all key architecture choices are captured and confirmed.
